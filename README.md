Code and processed data for Lemieux et al. 2026* paper describing PBD-peptide interaction strength by DHFR PCA. The raw sequencing reads are deposited as an SRA BioProject (PRJNA1499819), which will be kept private until the publication of this work. Please refer to the preprint on BioRxiv for the detailed methods. 


## Layout

    code/    scripts to analyze the data and generate figures
      analysis_PCA1/  analysis for the first PCA bulk experiment (double mutant library PPI and availability)
      analysis_PCA2/  analysis for the second PCA bulk experiment (double & single mutant library specificity and availability)
      library_design/  code to design the peptide library and generate the DNA sequences 
      read_processing/ code to aggregate read count from fastq files
      validation/  code to analyze the validation experiments (in silico prediction, cytometry, growth curves, etc.)
      figures.R
      functions.R
    data/   directory with the data used for figure generation 
      PCA1/  contains all files generated by the code/analysis_PCA1/
        aggregated/  input for the code/analysis_PCA1/1_read_count_analysis.R 
      PCA2/  contains all files generated by the code/analysis_PCA2/
        aggregated/  input for the code/analysis_PCA2/1_read_count_analysis.R 
      validation/   data obtained from the literature and validation experiments used in the validation/*.R scripts
